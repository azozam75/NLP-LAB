## Running the notebooks

Open a notebook from its lab folder and run the cells from top to bottom. Keep the included `dataset` folders beside the notebooks. Setup cells install missing Python packages; the first download of pretrained models requires internet access.

The Amazon reviews CSV in Lab 4 is stored using Git LFS because of its size. Install [Git LFS](https://git-lfs.com/) before cloning, or run `git lfs pull` after cloning to retrieve that dataset.

The notebooks include dataset sources, methodology, evaluation results, and limitations. Original lab instructions are linked in each notebook.
